# Hotel Reservation System

## 📌 Project Overview

Hotel Reservation System is a Java-based console application developed to manage hotel rooms and customer reservations.

The system allows users to search available rooms, make reservations, cancel bookings, view booking details, and simulate payment.

## 🎯 Objectives

- Manage hotel rooms
- Search available rooms
- Make new reservations
- Cancel reservations
- Calculate booking amount
- Store booking information
- Simulate payment methods

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- LocalDate
- Console-based Interface

## 🏨 Room Types

The system provides three types of rooms:

- Standard Room
- Deluxe Room
- Suite Room

## ✨ Features

1. View available rooms
2. Search rooms
3. Book a room
4. Enter customer details
5. Calculate total booking amount
6. Payment simulation
7. Cancel reservation
8. View booking details
9. Save booking information in `bookings.txt`
